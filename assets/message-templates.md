# 可复用消息模板

下面是需要时复制并填入真实事实的模板，不要求每轮逐项机械填写。删去无关字段；缺失的关键字段写未知，禁止编造。

## 首次交接给主管

```text
用户让你主管本任务，Codex 负责信息桥接与执行。

用户目标与预期交付：
用户最新原话：
目标的后来修改及日期（仅用户明确修改）：
尚未采纳的主管建议/解释：
现状：已经完成 / 正在运行 / 未完成，附必要版本和输出。
现有通道与资源：本机执行环境、远端可用能力、工具的具体用途与限制。
授权：可发送的材料、可执行范围；暂停项、禁止项。
材料：按需附公开或已授权代码、报告和结果；不附凭据/敏感原始日志。

请先说明你对目标和现状的理解，再安排优先任务、分工、模型与思考档位、资源/截止时间、输出，以及你认为必要的验证。
你负责方向、拆分和节奏。Codex 不自行增加审计或局部优化，只承接指令和回传事实。
如某项工具或材料不可用，请给 Codex 明确的补取指令；不要假定已看到本机文件。
```

## 本轮结果回传

```text
对应任务 / request_id：
用户新增指示（如有，原话）：

实际使用的入口/输入清单/数据目录/输出目录（本轮运行相关才填）：
真实结果：退出码、必要输出、产物路径、未完成部分。
你要求的验证：完成哪些；未要求则不自行增加。

并行状态：哪些还在运行，是否占用主管会话。
请据此安排下一步。下面附完整必要材料：
```

## 独立 worker 请求

```text
这是主管分配的独立任务，不接管主管会话。
任务目标：
输入版本与必要材料：
允许写入的相对路径：
不得改变的接口 / 用户约束：
模型 / effort / 时限：按主管安排。
logical_task_id / attempt / part / controller_request_id：
通道版本：v1 或明确启用的 v2；不同通道输出协议不得混用。
期望输出：完整文件或明确补丁，以及运行指令、未完成事项。

你不能访问本机未提供的文件；若禁用工具，不要声称读过本机或跑过命令。
如需返回完整文件，输出一个 JSON 对象：
{"files":[{"path":"relative/path","content":"完整文件内容"}],"commands":["主管要求的命令"],"notes":["限制与说明"]}
不使用省略号、伪代码代替必要内容。无法完成时明确说明，不把部分成果标为完整。
```

上面是 v1 通用文件包示例。当前 v2 仅支持最多两个 Python 文件、总公开文本 12000 字符、每个文件的 `# END <path>` 与 AST 检查；给 v2 任务使用 [并行承接](../references/parallel-execution.md) 的完整协议，不能直接复制上面无限文件的示例。预算由主管指定，首公开时限与总预算分开。

## 方向改变

```text
用户最新原话：
原目标中停止的部分：
仍然有效的约束与授权：

请以用户最新目标重新安排；旧任务产物保留，是否使用由你决定。
```

## 在途任务移交给唯一写入者

```text
移交依据：用户授权或原执行者明确交接；原 owner / 新 owner。
当前主管 session_id；pending request_id 和原 prompt 路径/SHA。
已确认远端状态、最后检查时间；哪些仍未知。
各 worker 的通道版本、原 task/receipt 路径及终态。
已完成落地；仅收到尚未执行；仍在运行；等待转达的用户新指示。
原预算起点/截止时间、已用重试次数、恢复动作权限。
接手后先收原请求，不新建 UUID 重发；不要重启仍可能存活的旧进程。
```

## 授权持续执行后的 heartbeat 提示骨架

```text
沿用指定项目、主管会话及唯一写入者。先读取 pending、回执、worker 和最后执行状态，已有请求只收状态，避免重复提交或写入。
用户当前目标：……。用户明确停止的旧目标：……。
当前有效的模型/并发/调用预算来自……；临时模型恢复时间……；临时调度频率恢复时间……（如不同分别列明）。
由 Claude 决定方向、任务拆分、模型、资源、节奏及验证；Codex 只桥接并执行已有授权内的指令。
任务有结果立即接回、归档、落地并反馈；按主管安排推进。保留公开原文，不发送凭据、私有推理或敏感原始材料。
没有新变化或可行动事项保持安静；只在重要结果、失败、交付或确需用户决策时通知。
```

时间间隔、自动化 ID、会话 ID 和暂停条件从当前真实配置取得。此模板本身不代表已创建自动化，也不授权新建任务。

## 实际额度查询回传

```text
查询时间与时区：
方式：隔离诊断 PTY 中的内置 /usage；未 resume 主管，未发送模型 prompt。
账户窗口：原屏幕 used / 换算 remaining / 原重置时间 / 本地时区换算。
未显示的窗口或重置时间：未知。
每请求 usage 与账户额度分列；本次输出不能证明供应商计费完整性。
```

## 独立直聊部署交接（模式 B）

```text
用户要直接与 Claude 对话，运行时没有 GPT/Codex 转述。
独立部署目录/本机配置位置：
已授权 SSH 别名及实际远端执行层（不附凭据）：
本机选定工作目录、远端 root/HOME/Claude 路径：
指定型号/effort/请求总时限：
新独立 session，不复用旧主管；旧主管及 worker 状态保持原归属。
工具：read_file/write_file/list_files；run_command 逐条展示命令、cwd和timeout，仅允许一次或拒绝。
本机入口可达 / 远端请求返回 / 原文留档 / 文件工具 / 批准与拒绝 / 原ID恢复：分别填写实际证据。
未验证：真实断网、休眠、长期稳定等未做项据实列明。
```

这不是要发给旧主管的新任务，也不是邀请模型自动执行模板中的示例。部署前配置实际运行时 config.json；交接记录模板不被程序读取。
